# odekake-log（おでかけログ）

Google Maps 連携の訪問記録アプリです。訪れたお店・スポットを検索して記録し、日付順（記録タブ）・場所別（場所タブ）・地図上（マップタブ）で振り返れます。

## セットアップ

```bash
npm install
npm run dev
```

`npm run build` で本番ビルド、`npm run preview` でビルド結果をローカル確認できます。

## Google Maps APIキーについて

アプリ右上の 🔑 アイコンからAPIキーを設定すると、Google Places によるリアルタイム検索とインタラクティブな地図が有効になります。未設定でもデモ用のプリセット候補と簡易リスト表示で一通り動作します。

キーの取得手順:

1. Google Cloud Console でプロジェクトを作成
2. **Places API** と **Maps JavaScript API** を有効化
3. APIキーを発行し、アプリケーション制限を「HTTPリファラー」にして配信ドメインを登録、API制限を上記2つのAPIのみに絞る
4. アプリのAPIキー設定モーダルに貼り付けて保存

キーはブラウザの `localStorage` に保存されます（サーバー送信はありません）。公開して不特定多数に使わせる場合は、必ずHTTPリファラー制限をかけてください。

## データの保存について

登録した場所・訪問記録は `localStorage` に保存されます。ブラウザやデバイスをまたいで共有されないため、バックアップが必要な場合は別途エクスポート機能の追加を検討してください。
